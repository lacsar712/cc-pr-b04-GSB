# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

顶栏可切到「印张过滤」专页：提交前缀即由服务端过滤（`GET /api/jobs?prefix=`，空前缀返回全部），前缀可保存为命名方案，切换方案立即重查。方案可增可删，每次变动都写入履历。印刷员与质检都能保存方案；只读账号能用方案、翻履历，但不能删别人的方案。

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮。
4. 投封面与内页各一笔，到「印张过滤」页把前缀「封面」存成方案甲，结果表只剩封面行。
5. 切回「全部（空前缀）」，封面与内页两行都在。
6. 删掉方案甲，方案履历里留下保存与删除两条记录；checker 登录删别人的方案会被拒。
